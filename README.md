# Intencionalidade — Atividades e Apresentações

Atividades interativas de sala de aula e apresentações que acompanham o livro
[*Intencionalidade, Vontade, Impulsividade e Livre Arbítrio*](https://henriquealvarenga.com/intencionalidade/).

Publicado em <https://henriquealvarenga.com/intencionalidade-atividades/>.

- `atividades/` — hub, atividades e painel do professor (HTML/JS puro; Supabase para as sessões de aula)
- `apresentacao/` — apresentações em revealjs (Quarto)
- `supabase/` — schema e políticas RLS
- `fonts/` — fontes self-hosted

```bash
quarto render          # opcional, conferir antes do push
git push origin main   # GitHub Actions publica
```
